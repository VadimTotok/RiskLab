# RiskLab: симулятор инвестиционных рисков

RiskLab: учебное веб-приложение для моделирования возможных результатов инвестирования с помощью метода Монте-Карло. Проект позволяет изменять параметры инвестиционного портфеля, анализировать распределение конечного капитала и оценивать вероятность убытка.

## Возможности

- Моделирование тысяч возможных сценариев инвестирования.
- Настройка начального капитала, ожидаемой годовой доходности, волатильности и горизонта инвестирования.
- Расчёт среднего и медианного конечного капитала.
- Оценка вероятности убытка.
- Расчёт Value at Risk (VaR) и Expected Shortfall (ES).
- Построение гистограммы распределения результатов.
- REST API для взаимодействия frontend и backend.
- Обработка некорректных входных параметров.

## Как работает модель

RiskLab использует метод Монте-Карло: многократно генерирует случайные сценарии изменения стоимости инвестиционного портфеля и анализирует полученные результаты.

Для каждого года моделируется валовая доходность:

$$
G_t = \exp(a + bZ_t)
$$

где:

- $Z_t$: случайная стандартная нормальная величина;
- $a$: параметр логарифмического дрейфа;
- $b$: параметр логарифмической волатильности.

Параметры модели калибруются по ожидаемой годовой доходности $\mu$ и волатильности $\sigma$:

$$
v = \ln\left(1+\frac{\sigma^2}{(1+\mu)^2}\right)
$$

$$
b = \sqrt{v}, \qquad a = \ln(1+\mu)-\frac{v}{2}
$$

Стоимость портфеля за каждый год рассчитывается умножением предыдущего значения на сгенерированную валовую доходность. После завершения всех сценариев вычисляются статистические показатели и распределение конечного капитала.

### Основные показатели

| Показатель | Значение |
|---|---|
| Средний конечный капитал | Среднее арифметическое результатов всех сценариев |
| Медианный капитал | Центральное значение отсортированного распределения |
| Вероятность убытка | Доля сценариев, в которых конечный капитал ниже начального |
| Value at Risk (VaR) | Квантиль распределения убытков при выбранном уровне доверия |
| Expected Shortfall (ES) | Средний убыток в худшей части распределения |
| Минимальный и максимальный капитал | Крайние результаты симуляций |

В текущей реализации используется уровень доверия 95%.

**Важно:** модель предполагает независимые годовые случайные доходности с логнормальным распределением. Она не учитывает автоматически комиссии, налоги, инфляцию и изменение рыночных режимов. Симуляция показывает возможные результаты при заданных предположениях, а не гарантированный прогноз.

## Пример API-запроса

Endpoint:

`POST http://localhost:8080/api/simulations`

Пример запроса:

```bash
curl -X POST http://localhost:8080/api/simulations \
  -H "Content-Type: application/json" \
  -d '{
    "initialInvestment": 100000,
    "annualExpectedReturn": 0.08,
    "annualVolatility": 0.20,
    "years": 5,
    "simulations": 10000,
    "confidenceLevel": 0.95
  }'
```

Параметры запроса:

| Поле | Описание | Пример |
|---|---|---:|
| `initialInvestment` | Начальный капитал | `100000` |
| `annualExpectedReturn` | Ожидаемая годовая доходность в долях единицы | `0.08` |
| `annualVolatility` | Годовая волатильность в долях единицы | `0.20` |
| `years` | Горизонт инвестирования в годах | `5` |
| `simulations` | Количество сценариев | `10000` |
| `confidenceLevel` | Уровень доверия для оценки риска | `0.95` |

Ответ содержит агрегированные метрики и массив `distribution` с интервалами гистограммы. Каждый интервал включает нижнюю границу, верхнюю границу и количество сценариев.

Результаты отличаются между запусками, поскольку модель использует случайные величины.

## Дисклеймер

RiskLab предназначен для обучения финансовой грамотности и демонстрации моделирования рисков. Он не является инвестиционной рекомендацией и не гарантирует точность прогнозирования реальных рыночных результатов.
